# FluxWorks menu wordmark

The menu wordmark is rendered from **Full Automation Squared**, an independent
Factorio-inspired display typeface by Landmine752. The font is distributed
under the SIL Open Font License; see `OFL.txt`.

The layered wordmark is kept deliberately restrained so FluxWorks reads as a
secondary title beneath the physical Factorio logo rather than as a separate
sign or interface panel. The finished asset lives at
`graphics/menu-simulations/fw-logo.png`.
