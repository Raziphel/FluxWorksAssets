# Shattered Planet terrain sources

These four original source materials are the authored inputs for the committed
Factorio tile atlases. No third-party terrain art is copied into the output.

Art direction:

- Red: fractured iron-rich basalt, dark phase glass, restrained ember flecks.
- Purple: violet matter crystal needles, phase grains, sparse gold resonance.
- Yellow: sulfur-gold electrochemical crust, ochre nodules, pale static traces.
- Green: emerald bio-mineral felt, dark stone, lime spores, dead copper fibers.

All sources are orthographic, edge-to-edge materials with neutral lighting and
restrained contrast so belts, machines, resources, and hazards remain legible.
